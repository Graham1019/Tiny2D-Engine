# Tiny2D Survivor v0.5.0-rc1 — release notes draft

## Project overview / platform

A C++17 macOS OpenGL engine portfolio with a playable 90-second arena-survival demo.
This is a **local RC**, not a published release. macOS **arm64 only**; deployment
minimum **26.0**, actually tested **26.5.1 (25F80)**. Intel/Universal are untested.

## Features

Five-level difficulty menu, automatic combat, fixed 60 Hz gameplay, collision,
batched sprites, event-driven hit/death/trail feedback, camera shake, HUD,
Victory/GameOver and restart. Existing developer scenes remain available.
No gameplay balancing changes are included in this packaging milestone.

## Installation / controls

Extract `Tiny2D-Survivor-v0.5.0-rc1-macos-arm64.zip`, then double-click
`Tiny2D Survivor.app` in Finder. No source tree, build directory or Homebrew is
required by the packaged runtime. A normal quarantined download may be blocked;
this RC does not claim public-distribution Gatekeeper approval.

1–5 select; Enter starts; WASD moves; automatic shooting; arrow keys offset camera;
Q/E zoom; R press/release restarts after Victory/GameOver; Escape exits.

## Build from source

```bash
cmake -S . -B build/m63c-release -DCMAKE_BUILD_TYPE=Release -DTINY2D_OPENGL_TESTS=ON
cmake --build build/m63c-release --parallel
ctest --test-dir build/m63c-release --output-on-failure
cmake --build build/m63c-release --target package_macos
```

Requires local CMake, Apple Command Line Tools, GLFW and libpng. See
[release architecture](../release-architecture.md) for dependency deployment.

## Tested environment

Apple Silicon, AppleClang 21.0.0 (clang-2100.1.1.101), macOS 26.5.1, deployment

is recorded in [environment](../data/m63c/environment.txt). Debug/Release 40/40,
Headless 23/23; independent extraction GUI smoke and bundle/signature/hash checks pass.

## Signing / notarization status

Ad-hoc signed, nested dylibs first and App last; strict deep verification passed.
**No Developer ID, no Hardened Runtime configuration, no Apple notarization.**
Local spctl reported `accepted; override=security disabled`; this is a pre-existing
host policy, not normal Gatekeeper acceptance evidence. No security setting was changed.
No Apple credential, tag, release or release-asset upload was used.

## Known limitations / manual acceptance

Only this development Mac was tested, not a clean Mac. Homebrew remains installed,
but load-command closure and live lsof confirm embedded third-party libraries.
Finder first launch/quarantine, resize, minimize/restore, multiple displays/Retina,
repeated reopen and human Lv.1/3/5 full sessions including Victory remain pending.
Three real PNGs are included in docs/media; Lv.5/Victory capture and video are pending.
